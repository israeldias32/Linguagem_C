01 · Foundations

Fundamentos da linguagem C

Conheça os elementos básicos de um programa e aprenda a interpretar o código em inglês.

💻

What is C?

Linguagem C: uma linguagem de programação utilizada para desenvolver sistemas, aplicações e programas eficientes.

📦

Variables and data types

Variáveis e tipos de dados: armazenam informações como números inteiros, números decimais e caracteres.

⚙️

Functions

Funções: blocos de código que realizam tarefas específicas e podem receber parâmetros.

Seu primeiro programa em C

Este exemplo exibe uma mensagem na tela.

/* My first C program - Meu primeiro programa em C */
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}

English tip: “Hello, world!” significa “Olá, mundo!”. A função printf() exibe texto na saída do programa. A função main() é o ponto de entrada usual do programa em C.

INTEGER

int age = 20;

int significa inteiro. A variável age armazena um número inteiro.

FLOAT

float price = 9.5;

float representa um número de ponto flutuante, usado para valores decimais.

CHARACTER

char grade = 'A';

char armazena um caractere, escrito entre aspas simples.

02 · Structures

Estruturas e lógica

Aprenda a controlar o fluxo do programa com condições, laços de repetição e vetores.

CONDITIONALS · CONDICIONAIS

if / else — se / senão

Uma estrutura condicional executa diferentes instruções dependendo de uma condição.

int score = 75;

if (score >= 60) {
    printf("Approved\n");
} else {
    printf("Not approved\n");
}

Vocabulary: if = se; else = senão; score = pontuação; approved = aprovado.

LOOPS · REPETIÇÃO

for and while — para e enquanto

Os laços de repetição executam um bloco de código várias vezes.

for (int i = 1; i <= 5; i++) {
    printf("Number: %d\n", i);
}

Vocabulary: loop = laço; number = número; repeat = repetir; condition = condição.

ARRAYS · VETORES

Storing multiple values — armazenando vários valores

Um vetor armazena vários elementos do mesmo tipo. Em C, os índices começam em zero.

int numbers[3] = {10, 20, 30};

printf("%d\n", numbers[0]); // Output: 10

Vocabulary: array = vetor/arranjo; index = índice; element = elemento; output = saída.

Input

Entrada: dados recebidos pelo programa. Exemplo: scanf() pode ler valores digitados pelo usuário.

Output

Saída: informações apresentadas pelo programa. Exemplo: printf() exibe dados na tela.

Debugging

Depuração: processo de encontrar e corrigir erros em um programa.
